# CSSP 观测输入：可审查的验证输入与用途裁定

2026-11-04，基线 `main`（工作分支 `task/cssp-observation-inputs`）。本报告与
`validation/data/cssp_observation_inputs/`（下称"输入包"）承接
[MATCHED_OBSERVATIONS §4](MATCHED_OBSERVATIONS.md#4-cssp补齐成本探针需要独立的数据任务)
的补齐任务：把 CSSP 公开暮光光谱整理成来源可溯、采集合同明确、用途有证据裁定的验证输入。
本报告不宣告任何"模型绝对精度验证完成"；数据包的验收是可复跑性，不是物理匹配。

## 1. 本轮结论

| 用途 | 裁定 | 核心依据 |
|---|---|---|
| 谱形（明确归一波段内） | **有条件可用** | 同夜同设备比较；月亮在地平线下；曝光窗口情景不确定度已用真实邻谱变化率定标 |
| 同夜衰减 | **有条件可用** | 7/3 晨窗 −12°→−6° 三深度连续采样；各点曝光方案不同，须按名义窗口情景折算 |
| 绝对辐照度 | **当前不适合作绝对裁决** | 白盘角响应、地平线可见度、暗残差、现场大气均无独立测量；上游绝对标定只被复现、未被独立认证 |

数据集内不存在可认证晴空的夜次：两个最有依据的夜分别受阻于邻站雾（7/3 晨窗）与
月光污染（7/18–19 晨窗）。这是有证据的否定结论，不是待补数据。

## 2. 数据包与复跑

输入包（`validation/data/cssp_observation_inputs/`）按"原始证据 → 标准化记录 →
派生诊断"组织，全部由 `tools/cssp_observation_inputs.py` 构建与核验：

- `sources.json`：整文件、整包、成员、响应四级来源身份分开声明；外部引用
  （旧两包）以相对路径 + SHA 锚定，不依赖 scratchpad 绝对路径。
- `records.json` + `spectra.csv`：42 条选中记录的原始标签、发布（错站 DRL）轴、
  正确 CSSP 轴、raw `.mat` 采集合同（serial/曝光/温度）、名义曝光窗口情景与
  未知量（null+理由）、逐记录质量掩码；谱摘录与官方 CSV 逐字节一致。
- `raw/mat/`、`raw/weather/`、`raw/jpl/`、`ephemeris/`：未改写的档案成员、逐字
  公开响应、JPL 独立抽查响应、上游 MICA 全表（UT1 按 UTC 处理，差 <0.4 s 已记录）。
- `calibration-extract.json`：meter 'a' 已生成标定结构的精简提取物，整文件身份
  `d90270171e417b1e…` 锚定；`replay.json`：逐记录处理链复现。
- `selection.json`/`conditions.json`/`operator.json`/`diagnostics.json`：全 13 会话
  盘点与筛选裁定、独立条件窗口、观测算子合同、场景诊断。

## 3. 关键事实

1. **来源身份**。官方 CSV 与作者仓库同一 SHA（`e0e3e895…`，25,481,368 B）；完整 raw
   档案（701,893,601 B）经一次顺序读取取得整包 SHA `e6f7a5c7…`，取代旧前缀身份。
   目标三谱成员按预测名全部命中。
2. **raw↔发布逐位联结**。对 `Preprocess.m` + `RawToAbsolute.m` 的 Python 移植在
   42 条记录上复现发布列：中位相对差 5×10⁻¹¹、最大绝对差 5×10⁻¹⁵（CSV 打印精度级），
   截零格逐一复现。上游除以的是**微秒**（1e6 尺度被拟合的修正因子吸收），移植按
   上游约定执行。这证明 raw 成员与发布谱是同一数据经同一管道；**不构成对绝对标定的
   独立认证**。
3. **设备合同**。CSSP 记录 serial `USB2+H14462`（wls 169–878 nm → meter 'a'），
   与 DRL 控制样本（`USB2+F00926`，339–1025 nm → meter 'b'）完全不同，控制样本配置
   不可转移。曝光方案与采集源码分支一致（≤4 s×10、8 s×5、32/60 s×1）。
4. **时间合同**。`invokeTime` 是取谱函数调用前的墙钟标记；原始记录无逐次曝光起止、
   无时钟同步日志。名义"零延迟连续曝光"窗口单列为情景（如 −6° 目标 2 s×10 → 名义
   20 s 总积分），中点只在该情景内导出；`N·T` 只是总名义积分，不是实测墙钟跨度。
5. **轴**。正确 CSSP 太阳/月轴来自 vendored 上游 MICA 全表（5 分钟结点）；
   两个最终窗口的 JPL Horizons AIRLESS 独立抽查与 MICA 一致至 ~0.001°。发布轴
   （DRL 错站）保留原文作对照，不参与任何 CSSP 裁定。

## 4. 夜次筛选与条件裁定

全部 13 会话（3192 列）按冻结规则（900 s 间隙分会话 + 天光量级 + 独立条件可得性）
盘点于 `selection.json`；入选两夜的分窗裁定见 `conditions.json`，全部可回溯到
归档响应。月相/月高来自 MICA 表与发布照度字段。

| 窗口 | 月亮 | KN38（35 km） | KBFD（70 km） | 裁定 |
|---|---|---|---|---|
| 7/2 黄昏（−6° 目标） | **+23°** | CLR | 窗内无观测 | 月亮污染 |
| 7/3 晨窗（−12/−9/−6° 三深度） | 地平线下（−44~−46°） | 目标窗 6/6 行 FG（谷雾 VV/OVC001） | 08:53Z `BR BKN039 OVC090` | 月亮干净，但邻站雾/霾云 → 绝对用途受阻 |
| 7/18 黄昏（−6° 目标） | 地平线下（−31°） | CLR（目标行） | CLR（±60 min 上下文） | **数据集内最干净窗** |
| 7/19 晨窗 | **+43~+50°**（照度 0.47–0.52） | CLR→高云进场 | FEW/SCT/BKN 演化 | 月光污染 + 高云，仅作月亮样本 |

邻站距离/高差/时移、IEM 是 GHCNh 结构化表示而非第二传感器、AERONET
（Penn_State_Univ 请求无数值；Toronto 272 km 白天数据）等限制逐条记录在案。
710 m 站点自身无任何原位气象证据；邻站雾既不证明站上有雾，也不支持认证晴空。

## 5. 观测算子合同

发布谱是经白盘的**半球下行光谱辐照度**，不是天顶辐亮度。任何比较前，模型必须按
`operator.json` 完成时间 × 波长 × 半球方向的三重积分：

```
y_ip = P_p{ ∫dt w_i(t) ∫dλ R_p(λ) ∫_Ω+ dΩ A(λ,Ω) H(Ω) cosθ
            [L_tw(λ,Ω,t) + L_bg(λ,Ω,t)] } + r_dark,ip
```

其中 `A`（白盘/光路角响应）、`H`（地平线可见度）、`R_p` 的线展宽函数、
`r_dark` 残差均无实测，`A=H=1` 是理想化而非测量；`P` 是上游发布管道
（已被逐位复现）。禁止：半球辐照度直接对比天顶辐亮度；不积分半球与曝光窗口
直接对比光谱；把夜谱中位数当已测背景扣除。

## 6. 用途矩阵

### 6.1 谱形 — 有条件可用

- **条件**：同一夜、同一设备（serial `USB2+H14462`）的记录间比值；月亮在地平线下
  的窗口；排除饱和标记记录（`c3114` 单次曝光触及 65535 上限，发布列含 4 个截零格）；
  归一化须声明参考波段（如 380–780 nm 梯形积分）。
- **证据 ID**：`replay.json`（联结）、`records.json quality`（掩码/截零）、
  `conditions.json`（月亮）、`sources.json`（来源身份）。
- **不可用**：跨夜谱比（温度/暗库/大气状态不同）；月光窗口的"太阳"谱形；
  UV 缺失列的短波端比值。

### 6.2 同夜衰减 — 有条件可用

- **条件**：7/3 晨窗是唯一的三深度连续序列（−12°→−9°→−6°，44 分钟）。各点曝光
  方案不同（60 s×1 vs 2 s×10），比较须按各自名义窗口情景折算有效太阳轴；
  `diagnostics.json` 用真实邻谱变化率定标了时间偏移的谱效应（−12° 处可见波段
  ≈ −7%/min，60 s 中点模糊 ≈ ±3.5% 能量差）。共同增益在同设备比值中可能消去；
  响应色散、时变背景、云不会自动消去。
- **证据 ID**：`diagnostics.json adjacent_change`（逐深度逐波段）、
  `records.json timing`（逐记录曝光方案）、`selection.json`。
- **不可用**：把 −7%/min 当误差棒（情景不是置信区间）；未折算曝光窗口差异的
  跨深度比值。

### 6.3 绝对辐照度 — 当前不适合作绝对裁决

- **缺口**（均为有记录的缺失，非推测）：白盘角响应 `A(λ,Ω)` 无公开曲线；站点
  地平线可见度 `H` 未特征化；上游绝对标定仅被复现未被独立审计；7/3 晨窗被邻站
  雾/霾云阻断，全数据集无认证晴空夜；暗残差与夜背景分离无原始测量；无任何原位
  柱量（邻站天气 ≠ 现场，远站白天 AOD ≠ 曙光柱）。
- **补齐路径**：向作者/公开渠道获取白盘角响应与安装几何；对目标窗口补充原位
  气象或独立影像证据；独立辐射标定审计；若需要晴空夜，按相同冻结规则筛查其余
  夜次（7/12、6/30–7/1 等仍保留在盘点中，未取得独立天气认证）。
- 在上述缺口闭合前，任何"绝对辐照度验证"结论都不应由本数据集签发。
