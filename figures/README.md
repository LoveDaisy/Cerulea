# Figure index — production representative candidates

This directory holds **candidate figures for the production pipeline**, to be
curated by the representation task (task 4 of scrum 11): it will select,
re-draw or drop entries.  Ordinary research output now lands in each theme's
own `experiments/<topic>/figures/` (gitignored run artefacts); validation
figures live in `validation/figures/`; retired/historical figures moved to
`experiments/retired/figures/`.
