方位 0° 面向太阳，±180° 背向太阳。太阳高度是折射前的几何输入。自动曝光会使暮光显亮；切换固定基准可比较绝对亮度趋势。显示使用无色适应、保色度 ACES 与 sRGB。

不是天空照片。
也不是调好的渐变。

太阳光谱进入大气后，被空气分子和气溶胶散射，也被臭氧吸收。这个取景器展示项目物理模型算出的总天空光，再将光谱转换为屏幕颜色。

大气预先求解，角度与参数在浏览器中连续重建。页面不运行 Python 服务，不需要下载光谱原始档案，也不依赖外部 CDN。

把边界留在画面旁

当前是海平面、晴空大陆背景气溶胶，太阳 −6° 至 90°，AOD550 为 0 至 0.3。臭氧只切换 0 / 300 DU，不代表连续臭氧模型。

一次散射使用球面几何与有限太阳源；多次散射为平面平行 SOS 近似。模型已有物理校验仍存在不通过项。紧凑编码与重建在暮光、近地平线和太阳邻域留有局部误差；本页不是精度认证。观感已由作者视觉终验确认（2026-11-18），这不替代精度认证。

有限太阳盘参与照明，但画面不绘制直射太阳盘。不包含地景、云、高站、深暮光 Monte Carlo 或其他气溶胶。黑暗下半球不是模拟出的地面。
