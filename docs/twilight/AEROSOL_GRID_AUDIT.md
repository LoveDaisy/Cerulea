# 气溶胶波长网格一致性审计

2026-11-01。在统一暮光太阳源的实验中发现并修复了一个独立的介质定义错误：
同一个 AOD550 大气，被切成单波长后会改变气溶胶的物理消光量。

`MieAerosol.relative_coefficients` 原来用查询网格估算归一分母：单波长时直接除以
该波长自身截面，因而相对消光恒为 1；不含 550 nm 的多点网格则插值或取最近点。
例如 rural 在 450/550/650 nm 的正确相对消光为 `[1.260983, 1, .780489]`，
旧单点查询却分别返回 `[1, 1, 1]`。`Atmosphere._restrict` 本应只做光谱切片，
但暮光引擎的 anchor MC 因此在每个波长使用了另一份大气。

修复将 Mie 的参考截面固定为真实计算的 `ce(550 nm)`。Angstrom 幂律本来已经在
550 nm 归一，删除了额外的网格插值重标定。未增加另一套光学实现。

独立验证先在修复前执行新增测试，结果为 **13 failed / 3 passed**；修复后新增
16 项及相关既有测试共 **28 passed**。测试直接检查 AOD550 定义、八种成员的
单点/无550/乱序/重复子集，以及完整大气与 `_restrict` 的系数一致性。

修复前后的独立进程还比较了八成员的 81 和 401 波长完整网格：所有消光和散射
数组均逐位不变。修复后，81 个逐点查询和去掉550的子网格与完整网格误差严格为零。
这些完整网格上的旧直接 MC 实验仍可复用；外部网格包含550，不能保证内部使用
单波长 anchor 的 twilight 引擎不变。

七组 golden 均按原参数重新计算，仅 twilight 改变。另以旧方法独立回放，逐位
复现原 twilight fixture，确认差异归因；其550列保持不变。只更新了
`tests/data/golden_twilight.npz`，另外六个文件的 SHA 和全部数值保持不变。
golden 是回归检查；正确性的依据是上述介质不变量与解析归一真值。

冷的非550单点查询需要额外计算一个550状态，实测八成员约4–30 ms增至8–60 ms；
后续查询仍命中既有LRU，约6–13 µs。含550的81点网格不增加物理波长。
401点网格超过256容量时可能重算已逐出的550状态，数值仍确定。

原始前后数组、红绿日志、fixture 字段差及 SHA 存于
[`validation/data/aerosol_grid_audit/`](../../validation/data/aerosol_grid_audit)。
该目录的 `probe.py after` 可在仓库根目录用 `uv run python` 复跑；`before` 模式
只用于旧源码基线，勿覆盖保留的历史数组。

完整回归：313 passed / 1 failed（355.34 s），失败项为上述旧 twilight fixture。
完成归因并更新该 fixture 后，单独复跑该项通过（5.40 s）；共314项覆盖通过。
这不是又一次完整运行，原始两份日志分别保留。

六项物理校验重跑后仍为 **3 PASS / 3 FAIL**。check1–5 的结果全部不变；check6
的两个单种子、low-budget anchor-MC 数值改变：−9° 为 .0124165→.0181585，
−12° 为 .00303369→.000763295 cd/m²，其抽样误差及据此计算的容差同步变化。
两项仍通过既有容差，不能据此声称物理精度提高；这种非单调变化也提醒我们不能
靠单次暮光 MC 的拟合好坏裁定机制。修复依据始终是 AOD550 网格不变量。
旧/新 `results.json`、运行日志与精确补丁均保留于证据目录；已据此更新当前护栏
和 check6 图。生产修复提交为 `5d6f793`。
