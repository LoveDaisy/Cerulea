这片天空的计算与边界

取景器使用 Cerulea 光谱天空颜色模拟器，不是摄影滤镜，也不是经验渐变天空。数据来自修复了观察视线积分的生产核心，采用 hybrid-sos 总场：球面一次散射加平面平行多次散射。参考与候选共享物理内核；参考只独立检验网页表示，不认证物理模型。

固定了什么

海平面、观察者 0 km，生产 clear 预设：HinterlandAerosol 大陆背景气溶胶、1.5 km 指数高度分布，地面反照率 0.1、地面气压 101325 Pa，默认垂直域至 200 km。Rayleigh / Mie / O₃ / NO₂ 与有限太阳源；折射开启。臭氧仅提供 0 与 300 DU 两种完整场景。清单记录实际有效积分设置。

连续不等于直接求解

浏览器重建总场 XYZ：世界角网格与太阳邻域角网格、log uint8 压缩、分区高度插值与 log-PCHIP AOD 插值。节点为 41 波长求解，利用太阳谱归一的三次传递在 81 点上积分 CIE。独立参考直接在不同方向用 81 波长求解，不读候选资产。

暮光、太阳邻域与近地平线仍有可见局部残差，尤其在高曝光。P95 不是峰值，也不是审美接受。项目的六项物理校验仍有 3 项 FAIL；相关模型近似不会因网页运行成功而消失。作者视觉终验已于 2026-11-18 通过；首次公网托管实测不由这个页面代签。

颜色与曝光

不做色适应，XYZ 转线性 sRGB，按亮度保色度 ACES，再 sRGB 编码。高亮与超色域会裁切。场景自动曝光使用固定世界网格第 99 百分位亮度的插值基准，不随相机视角变化；固定基准使用倍率 1。EV 每加 1，输入亮度乘 2；范围 −4 至 +4。

没有绘制的部分

直射太阳盘、地景、云、深暮光 Monte Carlo、高站与其他气溶胶都不在此页。模型内部有限太阳盘的照明与屏幕画太阳盘是两件事。太阳输入为折射前几何高度，相对太阳方位 0° 面向太阳，±180° 背向太阳；太阳在天顶时方位退化，不代表新物理结构。

源码中的解读入口

仓库文档 docs/physics/MAINLINE.zh.md 提供读者主线，docs/STATUS.md 列出现行物理验证边界，docs/physics/SINGLE_VIEW_INTEGRATION.md 给出本次积分修复与独立证据。网页生成与原始对照见 docs/web/README.md 和 docs/web/VALIDATION.md。这些是仓库相对路径，独立静态包不要求额外下载这些文档。

可在项目仓库继续阅读：物理模型主线、当前物理验证边界。这是用户主动打开的外部文档链接，不是网页运行依赖。

设备验证不是桌面模拟

需要支持 WebGL2 与 DecompressionStream(deflate) 的浏览器。HTTPS 或 localhost 使用原生 SHA-256；普通局域网 HTTP 使用仓内 SHA-256。缺少能力会显示错误，不用旧画面假装加载成功。

真机验收：在用户授权的静态托管通道打开此目录；检查两个臭氧状态、−6° 与 90°、AOD 0 与 0.3；快速反向拖动太阳与气溶胶；拖动天空、缩放、展开视角、EV ±4；后台再返回、旋转屏幕、重新进入页面。记录设备型号、系统、浏览器、冷／热网络条件及任何错误。没有可访问的授权通道时，不代表已经测过真手机。
