## check2 — CIE 110 DHI / G173 / Bird 合同审计

被对照模型侧：`model_case`（`clear` preset、AOD₅₅₀=0.05、O₃=300 DU、海平面、

### 2a G173 对照前提 —— **成立（带「标准文本不可得」不可裁决子项；复算 + 复现二级）**

已核查（复算，recheck 2a 段）：

- G173 CSV 本身在库（`data_raw/ASTMG173.csv`，SMARTS 2.9.2 生成）。光度积分
  复算 97.142 klx / 宽带 900.14 W m⁻² → 光效 **107.92 lm/W**，与 check2 常数
  107.9 一致。
- O₃ 前提：check2 G173 段用 `ozone_du=343.8`，与 G173 惯引的 0.3438 atm-cm
  逐字对应（数值同源；标准文本本环境不可达，见下）。
- **透过率比探针** ρ(λ) = t_G173(λ)/t_model(λ)（G173 DNI/地外谱 ÷ 模型
  `direct_sun_transmittance`，同 48.19° 路径）：连续谱（排除吸收带）
  **中位数 0.9922**（p10–p90：0.9858–0.9965）——模型在 AOD₅₅₀=0.0734 +
  O₃ 343.8 DU 下的非吸收连续谱与 G173 直接束在 ~0.8% 内对应（Rayleigh +
  O₃ + 气溶胶载荷的综合对应；标准文本不可得，ρ 的分解归因是推断）。
- **模型缺失吸收的光度上限**：水汽 720 nm 带 ρ 谷最深 −26%，但该带的光度
  加权份额仅 **0.013%** 的 DNI-lux；O₂ A 带（760 nm）ρ 谷 −87%、份额
  **0.000%**。即模型缺失水汽/O₂ 吸收**不可能**解释 DNI 光度积分的量级
  （+4.8% 偏差的主导不是缺失吸收——候选 3 的 DNI 侧上界）。
- 模型 AOD(G173 案)：380=0.1067、500=0.0827、550=0.0734、700=0.0506
  （Hinterland，Ångström α≈1.01）。
- **不可达声明**：ASTM G173 标准文本（nrel.gov 与 astm.org 在本环境不可达；
  Gueymard 站点无参数表），其 rural 气溶胶 τ(λ)、水汽柱 1.42 cm 等**声明值
  未获独立原文核对**——该子项裁定「不可裁决（标准文本不可得）」，上述 ρ
  探针是替代性复算证据。

### 2b Bird & Hulstrom 转录 —— **成立（复现二级 + 复算）**

repo `bird_clear_sky` 与 pvlib 0.11.0 `pvlib.clearsky.bird` 源码逐常数比对
（pvlib 引 SERI/TR-642-761 与 Myers NREL Excel 实现）：Rayleigh/O₃/气体/水汽/
气溶胶透过率、`taa`、`rs`、DNI 与散射项 `ias`、GHI 反照率修正
`(1−albedo·rs)` 全部常数级一致；`aod_bb = 0.27583·AOD380 + 0.35·AOD500` 与
pvlib `bird_hulstrom80_aod_bb` 逐字相同。两处已识别偏差（复算，recheck 2b）：

- `dni_extra`：repo 1361.0 vs pvlib 默认 1364 → DNI **+0.22%**（repo 偏保守）；
- 相对气团式：repo Kasten-1966 形 vs pvlib 调用方 Kasten-Young-1989 →
  am 差 +0.077%（h=30）/ +0.033%（h=60），对 DNI 影响 ≤0.1%。

谱假设（宽带 W → lx 用 107.9 lm/W 单值映射）：该常数本身即 G173 直接束的
宽带光效（复算 107.92）， Bird 束谱形与 G173 的差异对 15% 容差判据的一阶
影响 ≤2%（推断；±2% 光效扰动不改变 DNI 对 Bird 的 PASS 裁定：+3.9%/+5.6%
偏差在扰动后仍为 PASS/边界）。

### 2c CIE 110 DHI 合同 —— **不成立（浊度对应前提）；量化闭合（复算）**

(i) **有效浊度与 T=2.2 的对应**：模型场景有效 Linke 浊度，两条独立链：

- CIE Yz 公式反解（由模型自身天顶亮度）：**TL ≈ 2.545（h=30）/ 2.528（h=60）**
  ——两高度自洽到 0.6%；
- Kasten-96 光度测量式（**内联转录**：常数逐字自 pvlib 0.11 源码
  `kasten96_lt` 核对，pvlib 本体不在本环境安装；出处 Ineichen 2008 /
  Molineaux 1998，转写链与报告数字同源可复算）：AOD_bb=0.0398、pw=0 →
  **TL=1.67**；pw=1.42 cm → **TL=2.64**。

T=2.2 的反推（同式，pw=1.42 cm）对应 **AOD_bb≈0.0009（AOD₅₅₀≈0.001）——
几乎无气溶胶**。check2 docstring 声称的「T=2.2 典型清洁大陆边界层
AOD₅₅₀~0.05」对应关系**未获任何一条链支持**（湿约定下 AOD 0.05 ↔ TL 2.6；
干约定下 T=2.2 ↔ AOD₅₅₀≈0.11）；Linke 对水汽的约定依赖本身在案（plan 风险 5）。

(ii) **两因子分解**（37×72 审计网格，recheck 2c；网格迁移：37×72 vs 判据网格
73×144 的 DHI 差 **−0.09%/−0.07%**，CIE 侧积分因子 73×144 相对 37×72 差
+0.04%/+0.05%（recheck 打印口径：ifac_cie_hi/ifac_cie − 1）——分解在网格误差内可迁移）：

| h | DHI 比 | Lz 因子（模型/CIE） | I 积分因子（模型/CIE） |
|---|---|---|---|
| 30° | 1.409 | 1.253 | 1.124 |
| 60° | 1.458 | 1.314 | 1.110 |

（DHI 比 = 37×72 审计网格模型 DHI / CIE(T=2.2) DHI，同网格相除：h=60 为
11.5713/7.934 = 1.458，两操作数由 recheck 2c h=60 打印锚按四位小数复算；
results.json 判据口径（73×144）为 1.4586 → +45.9%。）

**docstring 的「T=2.2 天顶亮度一致 3%」声称不成立**：实测天顶亮度比
**+25.3%（h=30）/ +31.4%（h=60）**（该声称此前无 metric 记录）。闭合检验：
模型天顶亮度对应的 TL≈2.54 与 Yz 斜率（1.376 kcd/T）预测的 +ΔYz（TL 2.64 vs
2.2）方向与量级一致——**天顶尺度因子即浊度对应缺口**。

(iii) **AOD 扫描**（h=30，37×72）：DHI_model/DHI_CIE(T=2.2) = 1.079（AOD 0.02）→
1.247（0.035）→ 1.409（0.05）→ 1.714（0.08）。对数线性**外推**（AOD* 低于最低
扫描点 0.02）得 DHI 比过 1 的 **AOD\* ≈ 0.005–0.012**（recheck 打印三个估计：
四点最小二乘零点 ~0.008、同斜率锚定 0.05 判据点 ~0.005、两点 [0.02,0.035]
外推 ~0.012——锚定与拟合零点之差即函数形式假设的方法不确定性，区间覆盖之；
结论「T=2.2 ≈ 几乎无气溶胶」对此稳健）。同节独立链：Kasten-96 反解
T=2.2 ↔ AOD₅₅₀≈0.001，与扫描链差数倍——DHI 比扫描折入了分布积分因子
（+11–12%）的超出而纯浊度链没有，两者在「几乎无气溶胶」的定性上一致。组合点
实测（recheck 独立 job）：AOD 0.02 + 反照率 0（两项对照前提都取「纯」端）时
DHI 比 = **1.009（+0.9%）**——CIE T=2.2 参考与「无气溶胶 + 无地面」的模型
场景一致。

(iv) **太阳轴**：Saemundsson 折射偏移探针（真/视高度差）：h=30 +1.75′ →
DHI +0.03%、Lz +0.07%；h=60 +0.59′ → DHI +0.00%（两位小数打印口径，recheck
探针行）。**可忽略**。16′ 盘面对
半球积分 DHI 的单独影响**未核**（生产源无盘面开关；aureole 局地特征的量级
由 AOD 扫描的太阳侧行为约束）。

(v) **Yz 公式**：`cie110_zenith_luminance` = Zotti 2007 §4.5 逐字
（"Yz,c = (1.376T − 1.81) tan h☼ + 0.38 [kcd/m2]"，归 CIE 110-1994）——
**复现（二级）**，数值复算（T=2.2, h=30 → 1082.8 cd m⁻²）。

(vi) **DHI 定义**：两侧同为光度亮度 × cosθ 半球积分（`common.
horizontal_illuminance`，CIE 侧 181×144、模型侧 73×144）；积分域/cos 权重/
方位平均实现核对一致，离散差见 (ii)。**成立（复算）**。

**2c 裁定**：对照合同**不成立**——不是 CIE 110 公式或实现错，而是**参考侧
隐含大气（T=2.2 ≈ 几乎无气溶胶 + 无地面）与被测场景（AOD₅₅₀=0.05 +
反照率 0.1）不对应**。DHI +41–46% 的分解：天顶尺度（浊度对应缺口）
×1.25–1.31 × 分布积分因子 ×1.11–1.12。场景匹配浊度（T_eff 反解自模型天顶
亮度，recheck 自洽口径）下 DHI 偏差降为 **+12.4%（h=30）/ +11.0%（h=60）**，
落入 25% 容差——但「正确」的 T 依赖
水汽约定（2.5–2.6 带），改判属 owner 裁定（见分流表）。

### 2d 地面反照率前提 —— **部分对应；量化在案（复算）**

三方前提：模型 `ground_albedo=0.1`（Lambertian，进 SOS 漫射场）；CIE 110 为
纯天空参考（无反照率参数）；Bird 参考自带 `albedo=0.2` 修正项
（`ghi=(idnh+ias)/(1−albedo·rs)`）。

复算（recheck 2d）：

- 模型侧敏感度：DHI(albedo 0.2 vs 0.1) = **+5.5%（h=30）/ +8.6%（h=60）**；
  DHI(0.0 vs 0.1) = −5.4%/−8.5%。天顶亮度对反照率也敏感（h=30：0.0 →
  −6.5%）。
- Bird 参考侧自带反照率项：rs≈0.083/0.077 → 其 DHI 被 **+1.7%/+1.6%** 抬升
  （albedo=0.2）。
- 三方对应：反照率自由度对 DHI 的敏感度为**相对模型 DHI 值 5–9%**（+0.1
  albedo）；折算到判据缺口（model/CIE−1）为 **~8 个百分点（h=30）/ ~12 个
  百分点（h=60）**——不足以主导 +41–46%，但非零：归因时不可把这部分计入
  「浊度」或「物理缺口」。
- 反照率探针同时校准 2c(iii) 的解读：浊度与反照率两自由度已解耦（扫描在
  固定反照率 0.1 下做，AOD* 是「含 0.1 地面」的有效等价）。

### 3a 公式保真 —— **成立（复现二级 + 复算）**

- 实现的 closed form 与 Zotti 2007 eq (4.31)（逐字引用 CIE 110-1994）同形：
  分子 (0.91 + 10e^{−3γ} + 0.45cos²γ)(1 − e^{−0.32/cosθ})，分母同构

- SOURCES.md「type 12 参数」注记成立；type 12 名称「CIE Standard Clear Sky,
  low luminance turbidity」与适用域 θs∈[10°,90°)（Darula & Kittler 2002，

### 4a 数值实现/转录 —— **成立（原文前提核对 + 复算）**

`validation/data/twilight_koomen1952.csv` 的直接来源是 Nawar 2020 Table 5
（二手转引）。本次回到原扫描逐深度核对 Maryland 天顶列（Table II，Z=0°、
P=90° 列）：**0/−3/−6/−9/−12/−15° 六行全部一致**（15 / 2 / 0.06 / 0.0015 /
0.00012 / 4×10⁻⁵ cd ft⁻²）。扫描深光度行使用「重复零下标」旧记法
（0.0₂15 = 0.0015），文本层 OCR 会丢一个量级；以栅格化页面视觉读数为准
（recheck `recheck_check6` 4a 段可复算）。−6° 两站值 0.022/0.060 与归档审计
（TWILIGHT_REFERENCE_AUDIT.md）一致。

换算链两条独立闭合（复算）：1 cd ft⁻² = 1/0.09290304 = 10.76391 cd m⁻²；

### 4b 物理量定义 —— **成立（带两项限定；原文前提核对）**

原文 p353 仪器段逐字：九级光电倍增管 **Type 1P22**，「covered with ground
glass and a **green filter**」，1.5° 视场；作者声称「The green filter caused
the spectral response to be that of the light adapted eye」（引 Plymale 1947）。

- **限定一（docstring 事实更正）**：`check6_second_dataset.py` docstring 声称
  "There is no filter in the optical train: the photometer response *is* the
  photopic curve" —— 与原文不符：光学链中**有**绿滤镜，其与 1P22 组合
  *以明视觉响应为目标*。仪器实际响应曲线未发表（Plymale 1947 给滤镜设计），
  与 CIE V(λ) 的偏差无预算。like-for-like photopic 声称在「明视觉目标」意义
  下成立，在「响应 ≡ V(λ)」意义下不成立。暮光光谱随深度变化（黄→红→蓝），
  近似 V 响应的谱依赖偏差在深度端不归零。
- **限定二（低照度修正未施加）**：原文 p353 右栏逐字："Since 0.003 cd ft⁻² is
  about the lower limit of the photopic level…During the second half the
  values need a correction which probably is not large. The correction was
  not made"（无误差预算）。0.003 cd ft⁻² = 0.0323 cd m⁻²：−6° 天顶值（0.646）
  在其上、**−9°（0.0161）与 −12°（0.00129）在其下**——即两个引擎点的参考值
  本身带一个作者自认未施加、未量化的系统修正。

绝对定标链（Macbeth 蓝滤镜照度计对晴天定标一点 + 钨灯传递 + 镭源检查）在案；
外推到深暮光的误差无预算（原文核对）。

### 4c 大气/站点前提 —— **成立（柱总量；复算 + 原文前提核对）**

viewed with the light adapted eye was … 75 to 85 percent」（1951 年 1–3 月），
